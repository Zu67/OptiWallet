# OptiWallet

Credit card optimization tracker. Cards you pick from the catalog are the wallet, and the app stores that choice in this browser. The document title is "OptiWallet - Credit Card Dashboard". `package.json` names the package `optiwallet` at version `0.0.0`. `index.html` loads Tailwind from `https://cdn.tailwindcss.com` and maps `react`, `react-dom`, `lucide-react`, and `recharts` to `aistudiocdn.com` at the same version ranges as `package.json`: React `^19.2.0`, lucide-react `^0.555.0`, and recharts `^3.5.0`. The Tailwind config sets `slate.850` to `#151f32` and `slate.950` to `#020617`. No component uses `slate-850`.

The browser keys are `optiWallet_cards`, `optiWallet_balances`, `optiWallet_creditUsage`, and `theme`. A missing key starts the wallet as `[]`, the balances as `{}`, and the credit checks as `{}`. `JSON.parse` is called with no catch, so a stored value that is not JSON throws before the first screen. The theme starts dark when `theme` is exactly `dark`, or when `theme` is missing and the browser prefers dark. Any other stored value starts light. The effect then writes `dark` or `light` back, so a first visit that prefers light stores `light`, and a later change in the system preference is ignored. A credit check is stored under `{cardId}-{credit text}`. Toggling the same card and the same credit text flips that one boolean.

The header labels are Overview, Strategy, My Wallet, Points, Credits, and Add Cards. Below the `md` breakpoint those labels move into the menu, and the theme button stays in the header beside the menu button. The menu has no theme control. The menu button has no text: it shows an X while the menu is open and a menu icon while it is closed. Choosing a label closes the menu. An id in `optiWallet_cards` that is not in the catalog does not count toward the wallet length, and it stays in the key. If every saved id is unknown, the length is 0 and the catalog opens with those ids still stored. The theme control has no text: dark mode shows a sun icon and light mode shows a moon icon. A missing `theme` key follows the system preference, and the first load writes that choice as `dark` or `light`. Any saved value other than the exact string `dark` is treated as light and rewritten to `light`. The other keys are `optiWallet_cards`, `optiWallet_balances`, and `optiWallet_creditUsage`. A saved value that is not JSON throws while the page is loading. A cards value that parses to something other than an array throws when the list is filtered. Removing a card leaves its balance and its checked credits in those two keys. Adding the same card again restores both. With no saved cards, the first paint is the Overview tab, so "Your wallet is empty" appears, and the effect then opens Add Cards.

The screen code is in `src/`. `src/constants.ts` is the card catalog. `src/components/` holds Overview, Strategy, My Wallet, Points, Credits, and the catalog screen.
